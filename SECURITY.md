# Security reporting

Please report suspected authentication or account-linking vulnerabilities privately through this repository’s Security Advisories, rather than posting exploit details in a public issue. Include the plugin version, WordPress/PHP versions, reproduction steps on a test site and the expected result. Never include real access tokens, passwords, OAuth codes, private signing keys or user identity documents.

Version 1.0.x is the initial supported release line. Keep WordPress, PHP and the plugin updated. Retain normal WordPress password recovery while enabling single sign-on, and test third-party MFA/membership integrations on staging.
